### ALCOR GNU/LINUX

</div>
<div align="center">
  <img src="https://github.com/laplace-daemon14/laplace-daemon14/blob/main/logo.png" width="130" alt="alcor">
</div>


Alcor GNU/Linux is an independent, lightweight, Arch-based operating system designed for developers, security enthusiasts, and penetration testers.

The project focuses on a clean host system, isolated security tooling, configurable deployment profiles, and a distinct Linux environment.

**Core ideas**

- **Focused host:** Keep the base system lightweight and organized.
- **Isolated tooling:** Use the Algol Distrobox environment for specialist packages.
- **Profile-driven deployment:** Choose an environment that fits your workflow.
- **Operator control:** Make system configuration and deployment choices explicit.
