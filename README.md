# <img src="logo.png" alt="Alcor Logo" width="60" height="60" align="center"> Alcor GNU/Linux

Alcor GNU/Linux is an independent, offensive security-focused, and lightweight operating system built on top of a robust Arch Linux base. Designed for enthusiasts, developers, and penetration testers who want a fast, clean, and highly customizable environment without system bloat.

> [!NOTE]
> **On "Independent":** While built on Arch Linux for a reliable foundation, Alcor maintains its own custom identity, configuration ecosystem, custom installer roadmap, and sandboxed toolsets rather than just being a pre-configured theme.

---

## ⚙️ What We Offer

* **Arch Linux Base:** Cutting-edge software, rolling-release model, and full access to the AUR.
* **Custom Boot Experience:** Fluid, custom-tailored Plymouth startup animation.
* **Optimized Environment:** Lightweight XFCE desktop setup paired with a pre-configured Zsh terminal and fastfetch.
* **Offensive Security Ready:** Architecture designed to run pentesting and security tools cleanly via isolated containers.
